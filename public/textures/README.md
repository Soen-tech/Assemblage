# Texture Analysis Image Assets

Place your custom tasting texture images in this directory (`/public/textures/`).
The application is pre-configured to look for these exact file names and render them dynamically in both the **Live Bottle Scan Results** and the **Journal History Entries** pages. 

If any file is missing, the app will automatically fall back to high-quality curated wine/whisky Unsplash photography so your interface remains beautiful.

## Required Image Filenames & Specifications

Please save your images in **JPG** or **PNG** format using the following exact file names:

| Texture Type | Intended for | Recommended Filename | Default Unsplash Fallback Placeholder |
| :--- | :--- | :--- | :--- |
| **Crisp & Vibrant Acidity** | High-acidity Wine | `crisp_vibrant_acidity.jpg` | Vibrant white/sparkling wine grapes & bubbles |
| **Velvety & Full-Bodied** | Smooth, oaky Wine | `velvety_full_bodied.jpg` | Deep rich red wine pouring into a crystal glass |
| **Oily, Rich & Viscous** | Heavy, intense spirits/whiskies | `oily_rich_viscous.jpg` | Golden amber whiskey swirling in a tumbler glass |
| **Silky, Smooth & Delicate** | Lighter, mature spirits/whiskies | `silky_smooth_delicate.jpg` | Smooth caramel-toned liquid reflect textures |

---

### Tips for Best Visual Quality:
1. **Aspect Ratio**: We recommend landscape (3:2 or 16:9) images for optimal rendering.
2. **Resolution**: Around `1200 x 800` pixels is ideal (keeps the file size light but looks sharp).
3. **Brightness**: Darker, rich, ambient imagery works best with the application's gold-on-black cosmic styling.
